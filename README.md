# Morpion

Un morpion à deux joueurs qui se joue sur le même écran. Le jeu est une page HTML autonome, sans installation ni dépendance.

## Jouer

Ouvrir [`morpion.html`](morpion.html) dans un navigateur. X commence. Les joueurs jouent à tour de rôle en cliquant sur une case vide. Trois symboles alignés font gagner la partie ; une grille pleine sans alignement donne un match nul. Le bouton **Nouvelle partie** remet la grille à zéro et redonne la main à X.

## Publication
